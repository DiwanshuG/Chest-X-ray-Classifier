# AI-Based Chest X-ray Classification Model

A deep learning project that classifies chest X-ray images into **Pneumonia**, **Tuberculosis (TB)**, and **Normal** categories. This project demonstrates the use of **EfficientNet** and **DenseNet121** models, along with a **Streamlit web app** for real-time predictions.

---

## 🔧 Tech Stack

- **Programming Language:** Python  
- **Deep Learning Frameworks:** TensorFlow
- **Pretrained Models:** EfficientNet, DenseNet121  
- **Web App Deployment:** Streamlit  
- **Version Control:** Git & GitHub  

---

## 🚀 Features

- Classifies chest X-ray images into **three categories**: Pneumonia, TB, Normal.  
- Initially trained using **EfficientNet**.  
- Improved accuracy to **94%** using **DenseNet121**.  
- **Interactive web app** for real-time image prediction.  
- Easy-to-use interface for uploading images and getting instant results.
